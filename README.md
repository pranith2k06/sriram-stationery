# Sri Ram Books & Stationery
A modern, responsive website for **Sri Ram Books & Stationery**

**Live site:** [https://sriramstationery.netlify.app/](https://sriramstationery.netlify.app/)

## Features

* Liquid glass design: frosted, see-through surfaces over a soft colour glow, with light edges that follow the mouse
* Floating glass header with a sliding highlight that follows the section you are viewing
* Responsive layout for phones, tablets and desktops
* Hero section with the shop front and four service buttons styled like the shop signboard
* Product category tiles with real photos from the shop and floating glass captions
* Print, xerox and money transfer section with UPI note
* Photo gallery with a full-screen viewer (tap a photo, then use arrows or the Esc key)
* Call, WhatsApp and Google Maps buttons, with a floating glass quick-action bar on mobile
* Light and dark mode with a toggle button; it follows the visitor's device setting and remembers their choice
* Respects the "reduce motion" and "reduce transparency" device settings
* No frameworks or build step: plain HTML, CSS and JavaScript

## Project structure


## Browser support
The glass blur works in all modern browsers. The extra lens-style refraction on the header, mobile bar and photo captions only shows in Chrome, Edge and other Chromium browsers. Other browsers get the frosted blur instead.

## Fonts
[Poppins](https://fonts.google.com/specimen/Poppins) for headings and body text, and [Noto Sans Telugu](https://fonts.google.com/noto/specimen/Noto+Sans+Telugu) for the Telugu shop name. Both load from Google Fonts.
